# 环境贴图跨面采样

Python 3.9+。运行 `python3 cube.py demo.json output.json`。faces 是按 `+x,-x,+y,-y,+z,-z` 命名的 6 个 N×N 线性单通道方阵，行号对应 v、列号对应 u。提供的 direction 和 locate 定义六面约定，绝对值轴相同时按 x、y、z 优先级。第 i 个像素中心为 2(i+0.5)/N−1。directions 是非零三维方向。samples 返回每个方向的跨面双线性结果。若中心面某一邻点越过边或角，将该邻点中心转换成三维向量，并在落入的面取对应最近像素，不在原面夹取。保持输入方向尺度不影响结果。

## 跨面双线性

双线性插值以物理球面方向为准，而不是把每个面当作互相独立的瓦片：

- 中心面内的四个邻点按像素中心 `c(i,N)=2(i+0.5)/N−1` 定位，权重由局部 (u,v) 与邻点中心的距离给出。
- 任何越出 `[−1,1)` 的邻点先用 `direction(face,u,v)` 还原为三维方向，再用 `locate` 落到相邻面（同一条规则同时处理跨边与跨角），在目标面取最近像素，绝不回原面夹取。这样立方体 12 条边与 8 个角两侧的采样是连续的，不会出现细黑接缝。

## 按像素立体角的预过滤

roughness 与 sizes 是等长列表，按位置一一对应：`levels[i]` 即粗糙度 `roughness[i]`、边长 `sizes[i]` 的贴图层。每一级输出 `{roughness,size,samples,faces}`。levels[i].samples 是对应输入 directions 的预过滤值，faces 是按该级 size 的六面预过滤结果。r=0 时使用跨面双线性过滤。r>0 使用归一化积分核 max(0,d·n)^k，k=max(0,2/r²−2)，k=0 时核为正半球的常数 1。

每个源像素的权重是“核值 × 投影立体角”：

```
weight(n) = max(0, d·n)^(k+1) * Ω(texel)
结果      = Σ radiance·weight / Σ weight
```

其中 `Ω(texel)` 用立方体矩形的精确立体角公式（atan2 差式，见 `texel_solid_angle`）计算，六个面的立体角之和为 4π（误差约 1e-14）。由于按真实立体角加权并做权重归一化，常量环境在任意粗糙度、任意层级、任意方向上保持常量；亮斑能量被归一化核约束在环境值域内，随粗糙度增加向半球均值扩散，不会出现亮度漂移或越界。

## 可复现性与粗糙度映射

积分是确定性的：固定的像素枚举顺序、精确立体角与解析核，不含随机采样。同一输入两次运行结果逐位一致；`seed` 字段按模式保留但不改变输出（确定性积分忽略 seed），固定输入即为可复现的粗糙度级别。粗糙度到贴图层的映射完全由输入的 `roughness`/`sizes` 并列列表决定，顺序与数值原样保留。所有计算和输出为线性亮度。

## 验收测试

`python3 test_cube.py` 运行 11 项 unittest，覆盖：

1. direction/locate 互逆、六面立体角总和 4π。
2. 常量环境在全部 12 边、8 角及两侧扰动方向的线性误差（实测 0，限值 1e-5）。
3. 用独立构造的六面正交基参考实现（不复用本模块的 direction/locate 算术）对照双线性；解析连续环境的跨边/角误差不高于同分辨率面内独立方向采样容差。
4. 旋转解析环境、5 个粗糙度级别的预过滤结果与 90×180 确定性球面积分核对照，预先指定方向的归一化积分均值误差（实测 ≤1e-4，限值 0.03）。
5. 固定 seed 复现、输出 schema、尺度不变性、r=0 双线性以及亮斑能量约束。

`python3 report_errors.py` 可打印上述误差的实际裕度。
