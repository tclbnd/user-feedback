# 数仓任务依赖与回填计划
Python 3.9+，标准库。入口 `python3 topo.py ops.json output.json`。
输入 `{"n":100,"ops":[{"op":"add","a":0,"b":1},{"op":"del","a":0,"b":1}]}`。节点为编号 0 到 n-1 的数据任务。a→b 表示先生成 a 的分区，再执行 b。重复添加和删除不存在的边是空操作。
输出 `{"order":[任务编号, ...],"rejected":[{"op":原操作,"cycle":[编号,...]}],"stats":{"affected_sum":整数,"recomputes":整数},"valid":true}`。成环的添加操作不更新图，cycle 首尾相同，以新边开头，并按现存依赖回到起点。计划为稳定的拓扑序，对同一最终依赖图结果一致。统计累计实际检查的受影响任务节点数和实际全量重算次数。
现有入口只在处理完所有事件后全量重算且接受成环边。
