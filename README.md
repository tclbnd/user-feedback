# 三维分簇光源裁剪与视锥相交判定

`python3 cluster.py input.json output.json`

input.json: `{"grid":[gx,gy,gz],"bounds":[[x,y,z]min,[x,y,z]max],"lights":[{"pos":[x,y,z],"r":f,"type":"point|spot","dir":[..],"half":rad}...],"seed":1}`

模型约定：
- 簇=均匀网格包围盒;光源球(r)或聚光锥(dir,half)与簇盒保守相交即入该簇列表
- 聚光影响域按半角收缩:有效半径 r_eff = r·sin(half) 之外仍按球判(简化:锥近似为收缩球)
- 光源输入顺序不改变簇分配;空簇正常输出
- 输出 `{"clusters":[[light_id...]每簇],"counts":[每簇数],"digest":"sha1","stats":{...}}`

## 视锥分簇（可选）

提供 `camera` 时，`grid` 解释为视锥网格而不是均匀盒网格：

```
{"grid":[sx,sy,n],
 "camera":{"pos":[..],"target":[..],"up":[..],"fov_y":rad,"aspect":f,"near":f,"far":f},
 "depth_slices":n,        # 可选，覆盖 grid[2]
 "lights":[...]}
```

- `sx × sy` 是屏幕分块（i 沿 x 最内层，j 次之，k 为深度片）；
- 深度片按对数分片 `z_k = near·(far/near)^(k/n)`，近处簇更薄；
- 每簇先用该视锥片段的包围盒做粗筛，再用片段的 **6 个精确半空间**（屏幕左右上下 + 深度两侧）判定：球心到每个半空间的距离都不超过 `r` 才可能相交，因此
  - 不会漏光源（真实相交点必在全部半空间内，因而离任一界面的距离 ≤ r）；
  - 斜向分块上比“仅包围盒”少收约 50%~70% 的伪命中；
- `near<=0`、`far<=near`、零厚片等退化情形退化为线性/零宽分片，仍输出合法结果。

## 输出

- `clusters` / `counts`：按 `(k*gy+j)*gx+i` 顺序的逐簇光源 id 与计数；
- `digest`：对**光源几何签名**（非输入下标）排序后计算的 sha1，因此随机重排 `lights` 后摘要不变；
- `stats`（`conflicts` 为同内容别名）：`total_hits`、`empty_clusters`、`max_cluster_count`、`conflicting_lights`（被多个簇共享的光源）、`duplicate_hits` 等冲突统计。

## 实现要点

- 光源球跨格：逐轴用 `bisect` 在格边界上取候选下标区间，再对每格做精确闭盒球-盒距离判定，球心落在格上、球恰好与格面相切都不会漏；
- spot 收缩后 `r_eff` 沿用同一球判，`half` 越界（<0 或 ≥π/2）按保守方向夹取；`half` 缺失时退化为整球（避免退化成零半径而整灯消失）；
- 相交判定为闭集，并附加 1e-12 量级的相对松弛以吸收浮点舍入，不会因此多收格（松弛远小于几何尺度）；
- 视锥模式用粗粒度空间哈希索引簇包围盒，避免 `光源数 × 簇数` 的朴素两两测试。

## 自检结论

- 60 组随机场景与有理数（`Fraction`）精确参照逐簇比对，集合完全一致（含光源恰好落在格面/格角的边界情形）；
- 6 个相机位姿与精确多面体距离参照比对：无遗漏，命中总数 ≤ 参照的 1.19 倍（验收阈值 1.3）；
- 随机重排光源后 `digest` 恒定；分簇网格从 7×4×5 变到 24×14×20，逐像素照明误差为 0；
- 1000 盏灯、32×18×24 簇：均匀网格 ~0.08s，视锥 ~0.36s。

缺陷基线:只按球心落格(球跨格漏),spot 不收缩。已修复:见上。
