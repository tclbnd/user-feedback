# 变速立体声重建

Python 3.9+，仅用标准库（无 numpy/scipy）。执行 `python3 stretch.py demo.json output.json`。

## 输入 / 输出契约

输入 `rate`、`blocks`（交错双通道的块）、`knots`（`[输出采样索引, 速度]`）。索引从 0 起，第一结点在 0，速度范围 0.7–1.6。速度在结点间线性，最后结点后保持末值。

逐样本时间映射（输出时钟 t 上的理论输入坐标）：

```
x(t) = ∫₀ᵗ v(u) du      # 每输出样本用梯形法精确积分（对线性 v 精确）
```

输出长度为满足 `x(t) ≥ 源帧数` 的最小整数 t；输出索引不含 t。块界不得改变连续时间状态——引擎是因果状态机，任意分块产出逐比特一致的结果。

输出：

- `frames`：双通道 `[左, 右]` 帧；
- `mapping`：每个输出采样的理论输入坐标 `x(t)`；
- `transients`：`[输入瞬态索引, 对应输出索引]`，输出索引用同一时间映射反解；
- `latency`：处理等待帧数（采样），成品坐标已补偿，不截掉输入的显式静音。

## 算法（`stretch.py`）

流式 **WSOLA（波形相似度重叠相加）+ 共享瞬态策略**：

1. **逐样本速度积分与读写映射**：`TimeMap` 在输出时钟上做梯形积分，帧的理想分析中心取 `x(t)`，输出长度由积分终点决定，文件结束时零填充收尾并按约定时钟截断到 `nout`。
2. **共享的瞬态与相位处理**：
   - 持续区用 Hann 窗长帧（32 ms 窗 / 8 ms 跳），在有界整数范围 `±D` 内用归一化互相关把每帧对齐到上一选中帧前进一个合成跳的“自然延续”位置。只移动读位置、不改写采样，因此音高保持。
   - 瞬态由流式能量比检测器（8 ms 窗 / 4 ms 跳，带预热、绝对地板与不应期）以固定前瞻确认，并自报“确定性 horizon”。瞬态附近切短帧（8 ms / 2 ms）、锁定校正量为 0 并重置延续状态（相位重置），鼓点只渲染一次、不拖成两次起音。
   - 左右声道共享完全相同的分析位置、校正量和窗，仅采样值不同，因此 OLA 与归一化精确保留任意声道关系（含精确反相）。
3. **可变块长接口**：`StretchEngine.process(block)` 接受任意块大小，`flush()` 收尾；`frame_log` 导出每帧实际时间映射（理想/实际分析中心、校正量、窗长、是否瞬态帧），`latency` 为处理延迟，`TimeMap.invert` 反解瞬态输出位置。短文件、全静音、速度极值边界均可复现且有限。

分块不变性由两条前瞻门控保证：瞬态判定窗口完全落在检测器 horizon 内、且有界相关搜索所需样本全部到齐才发帧；`flush` 抬门并用零填充处理尾部。

## 验收

```
python3 test_acceptance.py   # 全部硬性验收（独立频率/脉冲检测器）
python3 stress.py            # 多种子随机分块、混合信号、边界与长度交叉校验
```

- 测试正弦主频偏差 0%（限值 1%）；含已知鼓点素材脉冲映射 p95 ≈ 2.5 ms（限值 15 ms），每个鼓点恰好一个脉冲；输出长度与理论积分误差 0 样本（限值 1）。
- 左右声道构造为精确增益/反相时，输出 Pearson 相关系数 −1.000000（限值 ≤ −0.995），且 `R/L = −1` 逐样本成立。
- 6+ 种随机分块（含 1 样本块）输出长度与每个峰值位置完全一致，最大逐样本差为 0。
- 全静音、1–17 样本短文件、0.7/1.6 恒速极值、空输入均有限且长度符合理论。
