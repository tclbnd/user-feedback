# 多轨自动混音：置信度 + 短时响度驱动的人声避让（auto-ducking）

## 用法
```
python3 automix.py req.json output.json
python3 verify.py            # 9 项验收，全部通过才退出 0
```

`req.json`：
```
{"tracks":[{"name":"vox","pcm":"vox.wav"},{"name":"music","pcm":"bed.wav"}],
 "target_lufs":-16, "fs":16000, "params":{"block":256}}
```
- 名称含 `vox` 的轨为人声侧链，其余轨为音乐床并共享避让包络。
- `params.block` 只改变渲染循环的分块；分析与增益曲线在绝对时间网格上一次性
  全轨计算，任意分块（含乱序处理）输出样本逐位一致。

## 处理链（全部纯标准库，float64，确定性）
1. **短时响度**：BS.1770 K 加权双二阶滤波一次跑全轨，100 ms 窗 / 50 ms 跳，
   滑窗平方和 O(n)；积分响度用 400 ms 门限块（-70 LUFS 绝对门 + -10 LU 相对门）。
2. **人声置信度**：帧能量（0.65）+ 过零率（0.20）+ 频谱质心（0.15），噪声门
   截断后做固定系数单极点平滑，输出 0..1。
3. **目标避让量**：`置信度 × 深度`，深度由人声/音乐短时响度差调节，置信区间
   保证稳态 ≥ 8 dB（基准 9 dB，上限 18 dB）。
4. **起-保-释包络**：dB 域定速 60 dB/s；起动 20 ms；目标消失后**保持 150 ms**
   冻结电平以桥接字间音节间隙，再以 300 ms 定速释放，消除词间泵吸。
5. **增益约束**：分轨静态增益由目标积分响度（对**避让后**混音两轮定点求解）
   与 4× 过采样窗 sinc 真峰（默认 -1 dBTP）共同约束；总线仅做静态保护，无
   时变限幅器。
6. **渲染**：帧包络在 dB 域线性插值为逐样本增益；每样本增益仅是包络的纯函数，
   因此分块大小/顺序不影响波形。

## 输出
- `mix.wav`：混音；`<name>.stem.wav`：各轨渲染贡献（人声/音乐床）。
- `envelope.json`：逐帧 `t_s / voice_confidence / voice_lufs / music_lufs /
  target_duck_db / music_duck_db / *_power_db`、逐样本音乐增益、响度与泵吸统计。
- `output.json`：兼容基线 schema（`out/gains/peak_db/lufs`）并扩展真峰、
  响度误差、包络与统计字段。

## 验收结果（`artifacts/report.json`，12 s 对白-音乐交替节目）
- 人声段音乐衰减 P10 = 9.0 dB（≥8 dB）；间隙泵吸事件 0，释放速率 ≤ 60 dB/s。
- 积分响度偏差 0.0 LUFS（≤0.5）；真峰 -4.36 dBTP（≤-1）。
- 4 种分块（256/512/1024/4096）逐帧包络差 0.0 dB、输出 WAV 逐字节相同；
  乱序块处理样本差 0.0。
- 人声静音后音乐经保持+定速释放回到满增益（尾段衰减 0.0 dB，帧阶跃 ≤3 dB）。
