# 保守体素覆盖

`python3 voxelize.py input.json output.json`。输入 `resolution` 为 2 的幂；工作域为 `[0,resolution]³`，面表 `triangles` 是三角面的数组，每个三角形给出三个 `[x,y,z]` 坐标。体素 `(i,j,k)` 占据闭立方体 `[i,i+1] × [j,j+1] × [k,k+1]`，任意面相交或只碰到顶点、边或面都计入。输出只包含工作域内体素。

## 算法

1. **保守覆盖（不漏边角）**：每张三角面只枚举其轴对齐包围盒外扩一层内的候选体素，再用分离轴定理 (SAT) 判定三角面与闭立方体是否触碰。候选轴共 13 条：3 条立方体法线、1 条三角面法线、9 条“立方体棱 × 三角面棱”叉积轴；零向量轴自动跳过。仅当某条轴上的投影区间严格分离（含相对容差 `1e-10`，吸收浮点误差）才判不相交，因此只触碰顶点、边、面的体素必然计入。
2. **稀疏八叉树自底向上**：先在哈希集合中去重占用叶，再逐层按 `(x>>1,y>>1,z>>1)` 归并非空子节点。内部节点 `child_mask` 为子节点位掩码之并，`occupied_leaves` 为各子节点占用叶数之和。全程只存储非空节点，不分配 `R³` 网格。
3. **确定性**：叶列表与各层节点均按坐标排序；摘要只依赖占用集合与层级结构，面表顺序（含重复面）不改变输出。

## 输出

`leaves` 是去重、按 `(x,y,z)` 排序的体素三元组。`levels` 按根深度 0 到叶深度 `log2(resolution)` 排列，每层含 `depth`、`count` 和按坐标排序的 `nodes`。节点字段为 `x`、`y`、`z`、`child_mask` 和 `occupied_leaves`；节点坐标为该深度网格的整数坐标，子节点掩码位编号为 `dx + 2*dy + 4*dz`。叶无子节点且只包含一个占用叶。空层输出空列表。

其余字段：

- `digest`：`leaves` 与 `levels` 规范化 JSON 的 SHA-256，面序变化后保持一致；
- `leaf_hash`：仅叶集合的 SHA-256，便于快速比对体素哈希集合；
- `merge_stats`：每次相邻深度归并的 `child_nodes`、`parent_nodes`、`children_merged`（归并掉的节点数）、`max_children_per_parent`、`full_parents`（八位掩码全满的内部节点数）；
- `scan_stats`：每张三角面的候选体素测试数与新贡献体素数。

运行时 stderr 同时打印逐层体素数（节点数）与归并统计。

## 测试

`python3 test_voxelize.py`：内置独立写法的通用凸多面体 SAT 暴力参考（全网格枚举），对薄片、细杆、顶点/边/面边角触碰、域外面等 7 类网格在分辨率 8、16（另加 32 压力用例）下逐体素比对，校验八叉树父子关系与归并统计，并验证随机重排面表后 `leaf_hash`/`digest` 不变、同输入复跑摘要一致。
