# 八叉树体数据等值面

Python 3.9+，无第三方依赖。

## 用法

```bash
python3 surface.py demo.json output.json   # JSON 网格
python3 surface.py demo.json output.obj    # 也可直接导出 OBJ
python3 test_acceptance.py                 # 验收测试
```

输入 `field` 为 `sphere`、`shell`、`torus`，`domain=[lo,hi]` 表示立方域，
`center` 默认为原点。`tolerance` 是几何距离误差阈值，值越小细化越深；
`max_depth<=7`，`seed` 用于随机重排八叉树平衡、四面体遍历和等值面遍历顺序。

## 算法

1. **误差驱动细化**：在候选叶的 27 个规则点估计到等值面的距离，距离过远的叶终止；
   对近表面叶计算二次 Taylor 残差和 level-set 曲率项，超过 `tolerance` 即细分。
2. **全 2:1 平衡**：平衡不仅检查面邻居，也检查边和角邻居，因此任意接触叶的深度差
   不超过 1。平衡队列按 `seed` 随机重排，但最终叶集合与顺序无关。
3. **共形四面体网格**：粗叶与细叶相邻时，粗面插入边中点和面对心，细面使用匹配的
   对角线；每个叶的边界面三角形再连接到叶心形成四面体。所有跨叶面共享整数节点键，
   因而不会产生 T 形接缝或裂缝。
4. **Marching Tetrahedra**：等值面交点按全局四面体网格边键去重。精确零值统一视为
   内部，所有从该格点出发的交点合并为同一顶点；退化三角形丢弃。三角形法线按有符号
   距离场梯度定向，保证共享边以相反方向出现。
5. **规范化导出**：顶点按坐标排序、三角形按顶点编号排序；随机叶插入、并行/随机遍历
   和导出顺序都不会改变输出的几何和连接关系。

JSON 输出为 `{vertices,faces,stats}`，`faces` 是三个零基顶点下标；
`stats.leaf_depths` 按深度统计所有叶，并包含叶和四面体数量。输出无重复面、零面积面
或非流形边。薄壳保留内、外两个闭合分量。

## 验收覆盖

`test_acceptance.py` 对球体、薄壳和跨粗细边界的环面检查：

- 连通分量与 Euler 特征：球 `(1,2)`、薄壳 `(2,4)`、环面 `(1,0)`。
- 每条三角形边恰好被两个方向相反的三角形使用；四面体界面逐节点相同，因此没有
  T 形接缝。
- 输出顶点到解析曲面的距离、解析曲面抽样点到输出网格的距离均不超过抽样点所在叶的
  对角线。
- 每个场使用 `0.20, 0.08, 0.03` 三个阈值，核对细化深度、网格规模随阈值变严而增长。
- 每套设置用五个不同 `seed` 随机重排八叉树叶子，规范化后的顶点、三角形和统计摘要
  逐项一致。
- 对球半径取网格对齐值（等值面恰好经过格点）重复测试，验证零符号规则和封闭性。
