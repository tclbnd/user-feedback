# 分片落地冗余条带与降级读取一致性

`python3 stripe.py input.json output.json`

input.json: `{"k":4,"m":1,"blocks":["AAAA","BBBB","CCCC","DDDD"],"ops":[{"op":"fail","disk":2},{"op":"read"},{"op":"rebuild"},{"op":"read"}...]}`

模型约定：
- k 个数据块 + m 个校验块组成条带；m=1 单奇偶可容忍 1 块失联，m≥2 多校验布局须容忍 m 块失联
- 可恢复范围内降级读取在线重建，返回字节与原始一致
- 超出校验能力（失联数>m）必须明确报错（errors 记录，reads ok=false），不得返回损坏数据、不得误写
- 重建(rebuild)写回后校验仍一致；输出 `{"reads":[{ok,data,degraded}],"errors":[..],"stats":{degraded_reads,rebuilds},"digest":"sha1"}`
- 失联序列可重放，统计摘要一致

## 实现说明（stripe.py）

- 编码：GF(2^8)（本原多项式 0x11D）上的 MDS 纠删码。前 k 行为单位阵（数据原样落地）；
  m=1 校验行系数全 1，即单奇偶 XOR；m≥2 校验区采用 Cauchy 矩阵 `G[k+r][c]=1/(x_r-y_c)`，
  任意 k 行子矩阵均可逆，因此任意 m 盘（数据/校验混合）失联均可重建。
- 降级读取：失联数 ≤m 时用 Gauss-Jordan 消元在内存中在线重建缺失数据块并拼出完整数据，
  只返回不落盘；仅校验盘失联时数据读取不算降级。
- 重建写回：先恢复全部数据 → 重算全部校验块 → 比对仍存活的校验块 → 一致后一次性提交
  （数据块与缺失校验块一起写回），写回后条带与原始逐字节一致；任一校验不一致则整体放弃写回。
- 不可恢复：失联数 >m 时 read 返回 `ok=false,data=null` 并写 errors，rebuild 直接中止，
  失联盘保持 `None`、存活块零改动、不清失联集合、rebuilds 不计数。
- 确定性：全部运算无随机状态，同一输入（含完整失联序列）重放得到完全相同的 stats/digest。

## 验证（verify.py）

`python3 verify.py`，覆盖：GF(2^8) 运算自检；3 组配比 (k,m)=(4,1)/(6,2)/(5,3) 下
全部 1..m 盘失联子集的穷举重建（共 133 个组合，字节级比对数据与全部校验块）；
超能力失联报错且不误写；降级读取不落盘；单奇偶 XOR 与完整生命周期；
失联模式重放摘要一致；4 组高配比随机生命周期压力测试与 MDS 子矩阵可逆性；CLI 端到端。
