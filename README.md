# 变速立体声重建

Python 3.9+。执行 `python3 stretch.py demo.json output.json`。输入 rate、blocks（交错双通道的块）、knots（[输出采样索引,速度]）。索引从 0 起，第一结点在 0，速度范围 0.7–1.6。速度在结点间线性，最后结点后保持末值。输入坐标 x(t)=从 0 到 t 的速度积分。输出长度为最小的整数 t 使 x(t)≥源帧数，输出索引不含 t。块界不得改变连续时间状态。可用时域重叠、频域或混合算法，持续信号保持音高，两个声道共享时间选择和瞬态处理。短文件或全静音保持有限。

输出 frames（双通道）、mapping（每个输出采样的理论输入坐标）、transients（输入和输出瞬态索引），以及 latency（处理等待帧数，成品坐标已补偿）。不截掉输入的显式静音。相同输入拆块后的输出长度及峰值位置一致。
