# LSCM 网格参数化：最小接缝与共形展开

自动把任意三角网格切成若干拓扑圆盘,做最小二乘共形映射(LSCM)展开,并报告
接缝、UV 岛与畸变统计。纯标准库实现,无需 numpy / scipy / igl。

```bash
python3 unwrap.py mesh.json output.json
python3 test_unwrap.py -v          # 验收测试(71 项)
```

## 输入 / 输出

输入 `mesh.json`:

```json
{"pos": [[x, y, z], ...], "tris": [[a, b, c], ...]}
```

输出 `output.json`:

| 字段 | 含义 |
| --- | --- |
| `uv` | 每个**输入顶点**一个 `[u, v]`(接缝处取主副本) |
| `uv_faces` | 每个**输入三角形**三个角各自的 `[u, v]`;渲染应使用此字段,接缝两侧因此拥有独立 UV |
| `seams` | 接缝边,输入顶点索引对 `[[a, b], ...]` |
| `seam_paths` | 接缝折线(共线接缝边合并成路径) |
| `islands` | UV 岛数量(每岛均为拓扑圆盘) |
| `island_faces` | 每个岛的代表三角形索引 |
| `energy` | 面积加权的尺度无关共形残差(0 表示共形) |
| `angle_err` | 最大逐角角度误差,弧度 |
| `area_dist` | 最大逐三角形面积畸变 `|log(A_uv / (s·A_3d))|` |
| `flipped` | 折叠(非正面积)三角形数 |
| `severed` | 被切开顶点的附加 UV 副本 `[输入顶点, u, v, 岛号]` |
| `stats` | 顶点/面/退化面/接缝边数与面积统计 |
| `digest` | 展开结果的几何哈希,与顶点编号无关 |

## 算法

1. **规范化**(`Canonical`)。按坐标焊接重合顶点,按几何键重新编号,剔除退化
   三角形(零面积、重复索引、零长边),并统一面朝向。此后所有决策都以此为基准,
   因此结果与输入顶点/三角形顺序无关。
2. **切缝**(`Cutter` + `Chart`)。把每个连通分量切成圆盘,接缝数量按拓扑最小化:
   - **角模型**。接缝的语义是 *角*(face, vertex) 的粘合关系:沿非接缝流形边
     粘合两侧角;接缝边不粘合,于是其两端各保留独立角,可携带独立 UV。
   - **圆盘判据**。chart 顶点为角的粘合类,chart 边按所用网格边计数,由此精确得到
     `chi = V - E + F`、边界环数 `b` 与亏格 `g = (2 - chi - b) / 2`;圆盘当且仅当
     `chi = 1, b = 1, g = 0`。
   - **分阶段切割**。闭合曲面先开边(在若干最短候选路径与单边中按实际展开质量择优);
     边界环过多时在 chart 层做最短路合并;亏格 > 0 时不断加入能严格降低亏格的
     非分离环。每一步都在试算后**验证**确有改进才接受,避免死循环与冗余。
   - **最小性收尾**。`_prune` 删除任何仍保持全岛为圆盘的接缝边;`_polish` 在接缝数
     不增的前提下迭代减少折叠三角形。最终闭合亏格-g 曲面的接缝图恰有 2g 个独立环。
3. **共形求解**(`LSCM`)。逐岛最小化

   ```
   E = 1/2 Σ_ij cot θ_ij |z_i - z_j|²  -  2 A_uv
   ```

   即 `∫ (u_x - v_y)² + (u_y + v_x)² dA` 的离散形式。Hessian 稀疏装配(每顶点仅与
   邻域耦合),固定两个顶点(规范化的最远点对)消去 4 维相似变换核,用 Jacobi
   预条件共轭梯度求解;小规模 chart 走直接法以确保收敛。
4. **统计与摘要**(`island_metrics`、`seam_paths`、`make_digest`)。畸变以三角形
   奇异值给出;摘要基于**几何坐标**而非索引,因此重排输入不改变结果。

## 验收

`python3 test_unwrap.py` 覆盖:

- **解析参照**。圆盘与圆柱(可展曲面)展开的能量、角度误差、面积畸变均为 0,
  且边长比处处一致(即平面等距),可与闭式解逐项核对。
- **接缝正确性**。非接缝内部边两侧 UV 完全连续(共享顶点身份一致);每条接缝边
  确实被切开;UV 无自交、无折叠。
- **确定性**。6 组随机重排(顶点重编号、三角形旋转/翻转/乱序、半边遍历乱序)下
  digest、接缝集合(按三维几何比较)、能量与各统计量完全一致。
- **最小性**。圆盘不切;环带仅一条子午线;环面接缝图恰 2 个独立环、边数为 `nu+nv`;
  亏格-2 恰 4 个独立环。
- **鲁棒性**。退化三角形、多连通分量、亏格 2、非流形边、蝴蝶结、空网格等。

LSCM 本身不保证单射(它是最小二乘,不是受约束的保拓扑展开),因此对非凸极强
的 chart 理论上仍可能自交;本实现的切缝与收尾(折叠三角形计数驱动的 `_polish`)
在测试覆盖的所有网格上均得到零折叠、零 UV 自交。

## 性能

纯 Python 实现,规模参考(单线程):

| 网格 | 面数 | 用时 |
| --- | --- | --- |
| 圆盘 32×32 | 2 048 | ~1.1 s |
| 圆柱 32×16 | 1 024 | ~0.8 s |
| 环面 24×16 | 768 | ~1.0 s |
| 圆柱 64×32 | 4 096 | ~6.7 s |
| 环面 48×32 | 3 072 | ~7.3 s |
| 圆盘 64×64 | 8 192 | ~11 s |

主要开销是 LSCM 的共轭梯度迭代(与面数近似 n^1.5)。若需更大网格,建议改用
numpy/SciPy 的稀疏直接解(如 `scipy.sparse.linalg.spsolve`);算法本身与求解器
无关。
