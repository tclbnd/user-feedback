# 谱通量起始点检测与节拍栅格量化

`python3 onset.py input.json output.json`

input.json: `{"sr":22050,"frame":1024,"hop":256,"audio":[float...]}`

模型约定：
- 谱通量(逐帧幅度正差分求和)计算起始强度，自适应阈值=局部中位数×k
- 起始点合并最小间隔(≥50ms)，节拍栅格按间隔直方图估计并吸附
- 输出 `{"onsets_ms":[..],"confidence":[..],"bpm":..,"digest":"sha1"}`，digest 仅覆盖起始点毫秒整数
- 帧长/帧移变化下判定应一致；音频必须确定性处理

缺陷基线：固定能量阈值——弱起音漏检、颤音段落误检；无合并、无栅格。
