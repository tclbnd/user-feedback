# 参数曲面自适应细分的裂缝消除

Python 3.9+，标准库。`python3 tessellate.py scene.json output.json`

scene.json：`{"patches":[{"type":"sphere","uv":[0,0,1,1],"center":[0,0,0],"r":1}, ...],"err":0.05,"order":[0,1,...]}`。每个 patch 是矩形参数域 [u0,v0,u1,v1] 上的四边面片；`type` 支持 `sphere`(经纬球面块) 与 `saddle`(双曲抛物面 z=x²-y²，`uv` 为 xy 域，可含"洞"——域中心 0.2 半径内不采样)。

要求：

- 每个 patch 按曲率误差 `err` 独立选择内部分辨率，但**公共边的细分因子必须一致**：取相邻两侧所需密度的较大者，向上取整到 2 的幂，允许任意层级差；相同世界空间边的两侧顶点序列必须逐点相同（顺序相反）。
- 粗侧沿公共边插入与细侧一致的顶点身份（共享同一顶点 id），退化三角形（面积 <1e-12 或重复顶点）不得输出。
- 顶点合并以 1e-9 容差做世界空间量化；`order` 给定的面片处理顺序不得改变最终顶点集合与三角形集合。
- 输出 `{"verts":[[x,y,z]...],"tris":[[a,b,c]...],"patch_stats":[{"id":i,"edge_factors":{"N":n,"S":n,"E":n,"W":n},"n_tris":k}],"digest":"sha256前16"}`。digest 对规范化（顶点排序+索引重映射）网格计算。

现有实现缺陷：每边因子只按本侧误差取（相邻不一致 → T 型缝）、顶点合并用 exact equality、退化三角形未过滤。
