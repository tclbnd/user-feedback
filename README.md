# 损坏样本区间的自回归插值与爆点检测

`python3 arfix.py input.json output.json`

input.json: `{"sr":48000,"samples":[float],"block":512,"seed":1}` — 信号内含爆点尖刺与置零损坏段(未标注,须自检测)

模型约定：
- 用相邻样本差分能量检测爆点区间(孤立尖刺与长损坏都要找),无误删干净段
- 损坏段用相邻干净段拟合 AR 系数双向插值,边界相位连续
- 输出 `{"out":[修复后],"repairs":[[start,len]...],"digest":"sha1"}`
- 复跑摘要一致;块边界不影响修复

缺陷基线:只认置零段线性插值,爆点不检。
