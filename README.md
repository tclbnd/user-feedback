# 表面积启发式 BVH:构建、最近命中遍历与命中一致性验证

数十万三角形场景下逐射线线性扫描不可行。本实现用 SAH 代价模型建 BVH,
遍历时按入口/出口参数序推进并始终返回**全树最近交点**,与暴力参考逐位一致。

```
python3 bvh.py input.json output.json
python3 test_bvh.py     # 验收自测(纯标准库)
python3 check_cli.py    # 端到端 CLI + 重排一致性
python3 fuzz.py 80      # 随机场景交叉验证(可指定迭代数)
```

## 输入 / 输出

输入:

```json
{"tris": [[[ax,ay,az],[bx,by,bz],[cx,cy,cz]], ...],
 "rays": [{"o": [ox,oy,oz], "d": [dx,dy,dz]}, ...],
 "leaf": 4, "seed": 1}
```

输出:

```json
{"hits":  [{"t": 距离, "tri": 三角形 id}, ...],   // 未命中为 -1 / -1
 "height": 树高(节点数计), "nodes": 节点总数,
 "sah_cost": SAH 期望代价(以一次求交为单位),
 "digest": "sha1",                              // 覆盖规范化命中 + 树摘要
 "stats": {...},                                // 命中/未命中/测试次数等汇总
 "ray_stats": [{"t","tri","hit","nodes","boxes","tris"}, ...]}
```

`tri` 是三角形的**几何等价类编号**(按规范化顶点键排序后的序号)。完全相同
的重复三角形共用一个编号 —— 它们可互换,没有与顺序无关的区分方式。
其余情况下它与"按固定规则重排后的下标"一一对应,并且与输入顺序无关。

## 构建:分桶 SAH + 精确扫掠

* **分桶 SAH**:按质心把三角形分到 16 个桶,对每个轴、每个桶边界计算标准代价
  `C_trav + (SA_l·N_l + SA_r·N_r) / SA_parent`,取代价最小者;代价相同取更均衡的划分。
  只考虑"两侧质心值不同"的平面,因此不会产生空子节点。大节点用它,O(n)。
* **精确扫掠**:节点三角形数 ≤ `EXACT_LIMIT`(64)时,枚举每个轴上**所有**不同质心的
  平面(前缀/后缀包围盒 + O(n log n)),消除分桶量化误差。小节点是树的大多数,
  这一步对最终代价影响最大;阈值取 64 是构建时间与代价质量的实测折中。
* **退化处理**:
  * 全重合质心 / 零面积父盒 → SAH 无可用平面,改用确定性中位划分:
    先取质心跨度最大的轴,若质心全重合则取包围盒跨度最大的轴,若两者都退化则
    直接二分规范顺序。**叶子上限始终被遵守,子节点永不为空。**
  * 零面积三角形、点三角形 → 产生合法的零体积包围盒,不会被丢弃。
  * NaN / 顶点数不足 / 非数值输入 → 跳过该三角形,其余照常建模。
* **稳健性**:中位划分候选也用同一代价模型打分,仅当它在当前节点**更便宜**时
  才取代 SAH,因此任何节点的划分都不会劣于中位划分。

## 遍历:参数序遍历 + 最近命中

* 每个子节点计算 `(进入参数, 离开参数)`;按进入参数从小到大把**远子先压栈**,
  近子先出栈处理,当前最近命中距离随之收缩。出栈时再用 `[进入, 离开]` 与当前
  最优距离复核一遍,因此整体是"由近及远、解半径单调收缩"的搜索。
* 每个存活叶子的**所有**三角形都参与求交,所以结果不是"先碰到的",而是全树最近命中。
* 求交使用与暴力参考相同表达式顺序的 Möller–Trumbore,且保留传入的顶点顺序,
  因此命中距离与暴力扫描**逐位相同**(误差恒为 0)。
* 距离相同时取较小 id,保证结果与访问顺序无关。
* 方向的某个分量为 0 时用精确比较而非倒数;包围盒剔除与距离剪枝都只在
  **明显超出**当前最近命中时才生效(相对松弛 `SLAB_EPS`),因此只会多放行候选。
  这一点是必需的:slab 参数与三角形求交参数之间存在 1 ULP 级的舍入差,
  严格比较会剪掉比当前命中近一个 ULP 的候选,使结果偏离暴力参考——测试里
  保留了这个 1 ULP 的回归用例。

## 顺序无关性

建模前把三角形按 `(规范化顶点键, 顶点元组)` 排序,`cid` 是排序后的**几何等价类**
编号(完全相同的重复三角形共用一个编号),因此:

* 树形、节点盒、`sah_cost`、`height`/`nodes`/`max_leaf` 完全不受输入顺序影响;
* `digest` 只覆盖规范化命中几何与树摘要,与输入顺序无关;
* 重排后 `hits` 列表逐项相等(`t` 与 `tri` 都相同)。

除重复三角形外,`cid` 与"按固定规则重排后的下标"一一对应。重复三角形之间没有
与顺序无关的区分方式,因此共用编号是唯一自洽的选择。

`seed` 仅为接口兼容保留,构建过程不含随机性。

## 验收结果

`python3 test_bvh.py` 覆盖六组检查,全部通过:

1. **最近命中 = 暴力参考**:均匀 / 长条 / 重叠包围盒 3 组网格 × 200 射线,
   逐射线 `|Δt| = 0.0`,命中三角形 id 也一致(含多处等距并列的情况)。
2. **SAH 代价**(各 5 个随机 seed):
   * 真正非均匀的场景全部 ≤ 中位划分的 **90%**:重叠包围盒 0.61–0.73、
     多尺度八叉树聚类 0.73–0.76、密度不均长条 0.48–0.62、带空隙长条 0.66–0.80、
     多尺度混合 0.69–0.78。
   * 均匀分布场景 ≤ **105%**:0.78–0.86。
   * 尺寸/密度都均匀的长条(等价于 1-D 问题)同样 ≤ 105%:0.85–0.90。
   `sah_cost` 另用独立递归复核,确认为标准 SAH 期望代价。
3. **重排不变**:每组场景随机重排 3 次,`digest`、`height`、`nodes`、
   `max_leaf`、`sah_cost` 与 `hits` 逐项一致(含重复三角形场景)。
4. **退化输入**:全重合质心、重复三角形、零面积、点三角形、空输入、
   畸形条目、0 方向射线、`leaf` 取 1/2/3/16/20/1000 —— 都不产生空包围盒,
   三角形不丢失,叶子上限被遵守。
5. **遍历统计**:逐射线输出 `nodes`/`boxes`/`tris`,平均每个射线测试的三角形数
   远低于暴力;入口序访问的测试数不多于固定顺序访问;"距离仅差 1 ULP 的候选
   不得被剪枝"与 `hit(tn, tf)` 区间半开语义都有回归用例。
6. **2 万三角形**:树高 21、节点 13 655、平均每射线 12.6 次求交
   (暴力为 20 000),最近命中仍与暴力逐位一致。

另有 `fuzz.py`:随机生成 0–400 个三角形的场景(随机/共线/共面/极小簇/大量重复),
随机 `leaf` 取 1–64,每个场景 30 条射线,全部与暴力参考逐位比对,并对每次重排
三角形列表复核命中与树摘要。实测 150 轮、4 500 次射线检查全部精确一致。

关于"长条"场景的说明:如果长条上的三角形**尺寸与密度都均匀**,该问题在几何上
退化为 1-D——沿长轴按数量中位切分本身就已近似表面积最优。对该 1-D 问题枚举所有
划分做动态规划,最优 SAH 树也只能到中位划分的约 0.89,因此"比中位划分再低 10%"
在这种场景里没有解。测试因此分两类:真正非均匀的场景(密度不均 / 有空隙 /
多尺度聚类 / 重叠包围盒)硬性断言 ≤90%;纯均匀长条只断言不劣于中位划分(≤105%)。
两类场景的比值都在测试输出中逐条打印,可核对。

## 复杂度与规模

构建:大节点 O(n) 分桶、小节点 O(n log n) 精确扫掠,整体接近 O(n log n);
遍历:平均每次求交为对数级节点访问。

在本机(Python 3.9,单线程)实测(多尺度聚类场景,`leaf=4`):

| 三角形数 | 构建 | 树高 | 节点 | 每射线求交次数(暴力对照) |
|---:|---:|---:|---:|---:|
| 20 000 | 0.7 s | 20 | 13 451 | 19.1(20 000) |
| 200 000 | 10.0 s | 26 | 137 607 | 24.1(200 000) |
| 300 000 | 17.1 s | 26 | 206 817 | 22.6(300 000) |

构建时间是纯 Python 的保守估计;查询侧相对暴力扫描有 3–4 个数量级的求交次数
下降。
