# 遮挡感知运动补偿插帧

Python 3.9+，标准库。`python3 memc.py request.json outdir`

request.json：`{"frames":[{"file":"f0.pgm"},{"file":"f1.pgm"}],"t":[0.5],"block":8}`。帧为 PGM(P2) 灰度图。对每对相邻帧在时刻 t（0<t<1）插值。可选参数：`search`（每级搜索半径，默认 8）、`levels`（金字塔层数，默认 2）。

## 算法

1. **双向块匹配**：在 frame0 块网格上估计前向流 f01（块→frame1 最佳位移），在 frame1 块网格上估计反向流 f10。SAD 准则，由粗到精金字塔（每级搜索半径 ±`search`），精层搜索范围取"粗级估计邻域 ∪ 零运动邻域"，再做半像素、1/4 像素精化。每个块独立计算，平局按固定规则裁决（最小 SAD → 最小 |dx|+|dy| → 最小 (dy,dx)），因此**块遍历/分块顺序不影响结果**。支持部分块匹配（越界候选按重叠区域归一化 SAD），使物体进出画面的运动也能估计。
2. **误匹配抑制**：零运动吸附（静止与运动候选几乎一样好时归零）；均匀内部块的多解歧义用扩大窗口（块+边缘余量）复评消除；置信度 = 匹配误差相对块纹理能量足够小且显著优于静止。
3. **逐像素精化**：每个像素在 3×3 邻域块流候选 + 零运动中用小窗口重打分，修正混合运动边界块（运动物体主导的块不应带走其中的静止背景像素）。
4. **一致性检测**：逐像素检查 `|f01(p) + f10(p+f01(p))| ≤ 1`（分量式），反向对称；不一致或低置信 → 遮挡标记。
5. **合成**（流为 I0→I1 坐标映射，时刻 t 位于 p 的内容在 I0 中位于 `p - t·f01`，在 I1 中位于 `p - (1-t)·f10`）：
   - 双向一致：`I_t(p) = (1-t)·I0(p - t·f01) + t·I1(p - (1-t)·f10)`
   - 仅反向一致：`I1(p - (1-t)·f10)`（仅在 I1 可见侧）
   - 仅前向一致：`I0(p - t·f01)`（仅在 I0 可见侧）
   - 皆不一致：交叉验证的单向补偿（补偿值须在另一帧重现），否则回退帧复制 `I0(p)`
   - 采样越界的方向自动降级到另一方向/帧复制。遮挡像素绝不混合，边界形态稳定。

## 输出

每个 (帧对 k, 时刻 t) 输出（两帧时省略 k）：

- `interp[_k]_{t}.pgm`：插值帧
- `occl[_k]_{t}.pgm`：遮挡图（遮挡=255）
- `mv[_k]_{t}.json`：块网格运动矢量（f01/f10）与置信图
- `stats.json`：`{"occl_ratio":float, "fallback_px":int, "mv_count":int, "outputs":{...}}`，`outputs` 含每帧决策统计（bidir / uni_i0 / uni_i1 / copy 像素数）
