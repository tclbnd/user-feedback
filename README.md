# 大气散射预计算查找表

Python 3.9+，标准库。`python3 atmo.py config.json output.json`

config.json：`{"lut_size":16,"samples":32,"seed":1}`（可选 `"sun_cz":0.7`）。构建两张查找表，网格均为固定均匀的 `lut_size × lut_size`，坐标 `mu = 2i/(n-1)-1`、`alt = 60j/(n-1)`：

- **透射表 T**：`T[i][j]`，值为从该点沿天顶角余弦 `mu` 的视线到大气顶（向下视线若触地则到地面）的光学透射率 `exp(-τ)`。大气：球形地球 R=6360km，标高 H=8km，密度 ρ(h)=exp(-h/H)，Rayleigh β=5.5e-3/km。
  - **球面几何**：路径长度、切点与地面求交都在球面上解析求解，不再是直线近似。
  - **地平线折射**：采用等效地球半径近似，所有射线-球求交使用放大 `REFRACTION=1.15` 倍的地球半径；密度仍按采样点的真实几何高度计算（该近似的自洽用法）。
  - **光学深度积分**：每段假设高度线性、对指数密度取解析反导数，并用 `expm1` 稳定形式避免近切点相消；常密度等任意密度剖面回退到中点公式。固定 `samples` 下结果确定。
  - 表外查询夹取到边界，表内双线性插值，跨边界连续。
- **内散射表 S**：`S[i][j]` 单重内散射亮度，沿视线对
  `T_view(0→s)·T_sun(s)·P(μ_scatter)·β·ρ(h(s))·ds` 积分：
  - **各向异性相位**：Rayleigh `P(μ)=3/(16π)(1+μ²)`，按视线/太阳方向的实际散射角余弦求值（太阳方位与视线相同，`sun_cz` 默认 0.7）。
  - **地球遮挡**：每个采样点对太阳射线做地面求交，进入阴影的点太阳透射率为 0；立即触地的视线整体为 0。
  - **多散射近似**：整个单散射积分乘常数 `MULTI_SCATTER=1.05` 补偿。
  - 视线光学深度沿用解析分段公式并累积到 Simpson 节点；整条积分用复合 Simpson 法则（样本数强制为偶数），内插太阳射线用半分辨率固定采样，成本 O(samples²) 且确定。

## 复现性与查询

- 固定 `lut_size`/`samples` 下输出**逐字节可复现**：每个纹素是其索引的纯函数，结果写回固定索引槽；`--order {sequential,reverse,chunks}` 与 `--threads N` 只改变求值顺序，不改变数据。
- output.json：`{"T":[[...]],"S":[[...]],"meta":{"lut_size":n,"samples":m,"sun_cz":0.7,"refraction":1.15,"checksum":"sha256前16"}}`，checksum 对 `{"T":...,"S":...}`（元素已 round 到 9 位）紧凑排序序列化后计算。
- 查询 CLI：`python3 atmo.py --query lut.json T cz alt` 与 `--query lut.json S mu h`，坐标越界夹取到边界，双线性插值在节点与表边界处连续。选项可放在位置参数前后任意位置。

## 验收测试

`python3 test_atmo.py`（无第三方依赖）覆盖：

1. 常密度剖面与解析光学深度 `τ=β·L` 对照、天顶指数壳层解析解、高空稀薄路径与 16000 样本参考对照、地平线折射透射率对照，相对误差 ≤ 0.5%；内散射与 240 样本高分辨率数值积分对照，误差 ≤ 3%。
2. 改变构建顺序（reverse/chunks）与线程数（1/4）后 T、S 与 checksum 逐元素一致；查询在表边界夹取、在网格节点与边界面连续。

注：地平线附近 T/S 随 `mu` 存在物理上的陡变，均匀网格 + 双线性插值在该窄角区的插值误差偏大；验收的 0.5%/3% 针对透射计算与纹素节点值，常规角度区（`mu≥0.15`）离节点查询同样在约 1% 内。需要全角度高保真时应增大 `lut_size` 或改用非线性 `mu` 映射纹理。
