# 离线帧序列的时域重建

使用 Python 3.9+。运行 `python3 taa.py demo.json output.json`，或添加 `--no-history` 取当前帧。无需安装库。

输入的 `frames` 为帧描述列表。每帧有 `size=[w,h]`、`camera=[cx,cy]`、`object=[ox,oy]`、`jitter=[jx,jy]`，以及可选的布尔型 `cut`。屏幕像素中心为 `(x+0.5,y+0.5)`，采样位置加相机偏移和本帧抖动得到世界坐标。前景四边形由物体偏移定义，背景不动。保留渲染器的场景和 CLI 契约。

输出每帧的 `color`、`weights` 和 `reasons` 均为按 y、x 排列的二维数组。记录真实历史权重和可区分的拒收原因。镜头切换、视口改变和首帧必须为零历史。当前像素可从历史足迹中选择有效采样，足迹内没有通过身份及深度检测的采样时权重为零。相机和物体均含分数像素移动。

回放时可从带 `cut` 的帧开始。该段的输出应与从同一个重置点开始计算一致。报告每帧历史使用率和拒收计数，可在帧对象中增加诊断字段。


## 多物体亚像素场景

原来的输入和输出保持可用。一个序列中的帧都含 layers 时，启用下面的场景格式，并采用固定 2×2 样本。size、jitter 和 cut 沿用。可选 view 表示从屏幕到世界的 2D 仿射矩阵，省略时取恒等。矩阵 [a,b,c,d,tx,ty] 将 (u,v) 映射到 (a·u+b·v+tx,c·u+d·v+ty)。输入矩阵可逆。

layers 每项为 {id,size,transform,depth,color}。id 为唯一正整数，size 为局部矩形的宽高，覆盖 [0,w)×[0,h)。transform 将物体局部坐标映到世界。depth=[z0,zx,zy] 定义 z0+zx·u+zy·v，越小越靠前。color 是 [0,1] 的常量线性亮度。背景使用原有世界坐标条纹，id 为 0，深度 0.8。同深度按 id 升序决定可见物体。第 (x,y) 像素的屏幕样本按左上、右上、左下、右下排列，偏移为 (0.25,0.25)、(0.75,0.25)、(0.25,0.75)、(0.75,0.75)。抖动为屏幕坐标偏移，在 view 之前相加。

历史重投影沿同一局部点映到上一帧的物体变换与 view，移除上一帧抖动。背景沿世界点重投影。历史源格点的间距为 0.5，从 (0.25,0.25) 开始。查询位置的双线性足迹只含非零权重样本。先按越界、物体 ID 和前帧预期深度（绝对容差 0.025）剔除，再归一化保留的采样权重。在运动覆盖边缘，不得把不同物体的亮度纳入历史。无历史样本、首帧、cut 或尺寸改变时，权重为 0；存在有效历史且启用累积时，应有正权重。局部亮度约束应使用同一物体的当前样本，可按有效覆盖量衰减混合。

每帧额外输出 sample_ids、sample_colors、sample_weights，均为 [y][x][sample]，sample_colors 为线性重建结果。每像素 color 与 weights 分别为四个样本的均值。reasons 仍为逐像素可解释字段。--no-history 和从 cut 起重放继续可用。

## 诊断与实现约定

两种场景的每帧结果都带 history_usage（实际获得正历史权重的样本占比）、rejection_counts（按可区分原因计数：first_frame、cut、size_change、disabled、out_of_bounds、id_mismatch、depth_mismatch）和 reset（该帧的重置原因，无重置为 null）。多物体场景另导出逐样本 sample_reasons；旧场景在内部以 8×8 子样本网格累积并导出 sample_weights、sample_reasons，像素 color/weights 为子样本均值，原始的 render() 像素中心契约与 CLI 保持不变。

历史混合只在通过身份与深度检测的同物体足迹内进行：先对双线性足迹做越界、物体 ID 和前帧预期深度（当前帧深度平面在历史样本局部点上的预测值，绝对容差 0.025）剔除，再按剩余权重归一化；混合强度按有效足迹覆盖率衰减，全部样本无效时历史权重为零且保留当前帧颜色。首帧若带 cut，重置原因记为 cut，因此从该 cut 帧截断重放与完整序列对应片段的输出完全一致。
