# 回填区间预留

用 `python3 reserve.py input.json output.json --journal journal.jsonl` 执行一批本地事件。输入例子在 `sample.json`。

`reserve.py` 管理命令行、日志和输出。`reservations.py` 把日志事件转换为租约状态。

## 实现要点

- **区间索引**：每个 key 维护一棵以 `(start, lease)` 为键的增广 treap，节点记录子树的
  `max_end` 与 `min_start`。重叠查询只沿可能命中的子树下行，不再扫描整个分区；
  `stats.overlap_checks` 是这些查询实际访问的节点数。相邻端点 `start == end` 不冲突。
- **到期索引**：最小堆按 `expires` 排序，处理每个事件前弹出所有 `expires <= at` 的租约，
  已释放租约留下的陈旧堆项惰性跳过。
- **校验**：按 `seq` 连续、`at` 不下降、事件字段合法。同序号同内容视为重放并复用原结果；
  同序号异文、缺号、时间回退、非法事件整批拒绝，退出码 2，日志和输出保持不变。
- **日志**：先追加并 `fsync` 每条已接受事件，再写输出。末尾无换行的半条记录视为未提交，
  重启时丢弃；已提交前缀中的损坏记录退出 2 且不改动任何文件。
- **崩溃点**：`--cut-after-journal N` 在序号 N 的记录刷盘后、追加后续事件和写输出前退出 75。
  N 已提交时同样立即退出。
- **输出**：先写同目录临时文件并 `fsync`，再 `os.replace` 原子替换。

## 测试

- `python3 reference_test.py`：与独立线性参考做差分对比，含相邻/交叉/多 key/到期重用、
  迟到发布、重复发布、错误令牌，以及 10,000 + 5,000 事件负载（检查节点数上限）。
- `python3 smoke_test.py`：命令行、日志提交顺序、两类故障恢复、日志损坏与原子替换。
