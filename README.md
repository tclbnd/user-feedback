# 陀螺仪稳像姿态解算

```
python3 stab.py req.json output.json
python3 stab.py --selftest            # 合成轨迹自检（17 项断言）
```

`req.json`：

```json
{
  "gyro":   [{"t": 0.0, "wx": 0.0, "wy": 0.0, "wz": 0.0}],   // deg/s @1kHz
  "frames": [0.0, 0.0331],                                   // 秒；非等间隔亦可
  "truth":  [[r, p, y]],                                     // 可选，deg
  "drop":   [[3.6, 3.9], [10.2, 10.55]],                     // 可选，已知丢包区间
  "crop_budget": 0.25, "hfov_deg": 60, "tau": 2.0
}
```

`output.json`：

| 键 | 含义 |
|---|---|
| `poses` | 逐帧稳像后姿态（deg）；单轴输入时退化为 yaw 数组 |
| `poses_xyz` / `poses_roll` / `poses_pitch` / `poses_yaw` | 分轴平铺 |
| `raw_poses` | 未补偿的积分姿态 |
| `intent_poses` | 分离出的有意运镜（低频轨迹） |
| `comp` | 逐帧旋转补偿矩阵 `R_comp` |
| `comp_gain` / `comp_deg` | 全局增益 / 逐帧补偿角 |
| `crop_ratio` | 边界空缺率（= 逐帧最大值） |
| `crop_ratios` | 逐帧空缺率 |
| `residual_rms` / `raw_rms` / `residual_reduction_ratio` | 残余角速度 RMS 与降幅 |
| `truth_err_deg` | 逐帧姿态误差最大值（三轴范数） |
| `gyro_gaps` / `frame_drops` | 丢包（检测+声明）与丢帧空洞 |

## 算法

1. **时间轴对齐**：陀螺仪按 `(t, wx, wy, wz)` 规范化排序去重（与输入顺序无关）。
   帧时间戳不做等间隔假设，全部用真实时间戳。
2. **姿态积分**：对 ω(t) 分段线性插值 + 梯形积分，得到连续不回绕的姿态角。
3. **角速度域高通**：把角速度重采样到均匀栅格（栅格周期内的**精确均值**，
   防混叠且零相位），再用 τ=2 s 半窗、tricube 权的局部多项式回归（LOESS）
   分离意图速率与抖动速率。在速率域而非姿态域做高通，避免积分漂移污染。
4. **端点处理**：端点带内只有单侧观测，用锚定窗（3τ、三次）单侧拟合，
   只依赖真实观测、不引入延拓假设。抖动若用镜像延拓，其偶分量会变成
   非零直流（实测端点速率误差可达 30 deg/s）。
5. **丢包处理**：丢包区间**不参与意图拟合**（缺测掩码），但积分时用平滑趋势
   跨越丢包。若用线性插值跨越，缺失的抖动会被积成永久偏置（实测两段
   0.9/1.0 s 丢包后累积 8° 与 17°，且随时间线性增长）。
6. **边界空缺率**：归一化针孔相机下把源帧四角映射到输出平面，与输出矩形做
   精确多边形裁剪，空缺率 = 1 − 交面积 / 输出面积。超预算时用确定性二分
   把补偿增益 `g` 降到刚好满足预算。

## 确定性

- 所有加权和用 `math.fsum`（与求和顺序无关）；权重由真实时间戳直接计算，
  不使用等间隔/窗长奇偶/数据长度等隐含假设；
- 邻域检索提供 `bisect` 与线性扫描两种实现（`smoother_impl`），逐位一致；
- 浮点输出量化到 1e-12，`-0.0` 归一为 `0.0`。

## 自检结果（`--selftest`）

合成工况：运镜 0.03–0.10 Hz（3–12 deg/s）、抖动 2.0–9.5 Hz（1.5–9.5 deg/s）、
16 s / 1 kHz 陀螺仪 / 30 fps 抖动帧时间戳 + 13 处丢帧、两段陀螺仪丢包。

| 指标 | 结果 |
|---|---|
| 残余角速度 RMS 降幅 | **96.4%**（9.708 → 0.349 deg/s），要求 ≥70% |
| 姿态误差（无陀螺仪丢包） | **0.525° max / 0.372° rms** |
| 姿态误差（含两段丢包） | **0.899° max**（剔除首末 2 s 后 0.829°） |
| 空缺率 vs 独立数值复核 | 最大偏差 1.43e-3 |
| 丢包识别 / 插值平滑 | 两段均检出，姿态连续（<90 deg/s） |
| 相同输入不同平滑窗实现 | 逐位一致 |

姿态误差主要来自**数据端点**：首末各 2 s 内窗口只能单侧观测，速率估计残余
0.2–0.8 deg/s（内部仅 0.03），积分后成为 0.5° 量级的端部偏置。有丢包时额外
增加约 0.35°：丢包期间抖动不可观测，只能按平滑趋势跨越。两者都是信息缺失
造成的，不是实现缺陷——用真值意图速率直接积分可得 2e-4°。
