# 谱通量起始点检测与节拍栅格量化

`python3 onset.py input.json output.json`

input.json: `{"sr":16000,"frame":512,"hop":128,"audio":[float...], "segments":[[s0,s1],...](可选)}`

实现（纯标准库，全程确定性）：
- 谱通量：Hann 窗 + 内置 radix-2 FFT，幅度谱先做 ±45Hz 频率域平滑（颤音的亚带频移在带内抵消），再逐帧正差分求和；3 帧 [0.25,0.5,0.25] 时间平滑抑制单帧毛刺
- 自适应阈值：`max(k·局部中位数, 局部中位数 + c·局部MAD) + δ`（k=1.8, c=4.5, 窗 400ms，δ 跟随全局中位数）——中位数/MAD 为稳健统计量，颤音段 MAD 增大自动抬阈，安静段阈值贴近底噪保住弱起音
- 峰值拾取：局部极大 + 抛物线插值；时间取**帧中心**，消除帧长相关偏差，保证帧长/帧移变化下判定一致
- 起始点合并最小间隔 50ms（保留置信度高者）；节拍栅格按间隔直方图（10ms bin，置信度加权）估计周期、圆均值估计相位并吸附
- 输出 `{"onsets_ms":[..],"confidence":[..],"bpm":..,"grid":{"period_ms","phase_ms","bpm","coverage","snapped_ms"},"digest":"sha1"}`，digest 仅覆盖起始点毫秒整数
- `segments` 支持乱序分段处理：帧由起点唯一确定，按起点去重排序后与整段处理逐比特一致（digest 相同）

## 验收

`python3 eval_acceptance.py`（合成标注集：强/中/弱起音 + 6Hz 颤音段 + 背景噪声）：

1. Precision/Recall ≥ 0.85/0.80，时间偏差中位数 ≤ 20ms，弱起音漏检 ≤ 缺陷基线（固定能量阈值）×1.2
2. (512,128) 与 (1024,256) 复跑匹配率 ≥ 95%；8 段乱序分段 digest 一致
3. CLI 契约冒烟测试

当前结果：P=0.94 / R=0.97 / 偏差中位数 1.9ms / 弱起音漏检 1 vs 基线 7 / 匹配率 0.985 / digest 一致；另在 5 个随机种子的数据集上全部通过。
