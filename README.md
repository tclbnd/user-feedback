# 字幕逐帧时间窗与碰撞布局
`python3 sub.py req.json output.json [--check]`

req.json: `{"fps":25,"dur":4,"subs":[{"t0":0,"t1":2,"text":"A"},{"t0":1,"t1":3,"text":"B长..."}],"w":320,"h":240,"font":16}`

## 约定

- **时间窗**: 帧 f 的时刻 `t=f/fps`, 激活条件 `t0 <= t < t1`(右开区间)。时间量按十进制
  字面量转成有理数比较, 所以 `t=0.4` 这类边界帧不受浮点误差影响, 开/关状态逐帧确定。
- **规范序 = 优先级**: `(t0, t1, text)` 升序, 与输入数组顺序无关。第一条贴底, 其余逐条
  向上堆叠(纯纵向), 条间留 `0.4*font` 间隙; 放不下的条目按规范序丢弃并计入 `stats`。
  可选 `max_columns>1` 时允许开新列(每列不窄于 `8*font`), 默认 `1`。
- **度量**: 窄字符 `0.5em`, 宽/全角(W、F)与 CJK/假名/谚文 `1.0em`, 组合与格式字符 `0em`,
  制表符 `2em`。行高 `= font*1.3`, 随字号动态计算(缩字号后行高同步缩小)。
- **断行/断词**: 空白是断点, 拉丁按词边界断开; CJK 等宽字符任意处可断; 行首尾空白裁掉,
  行内多空格原样保留。单个词比可用宽还宽时, 先缩字号; 到下限仍超宽才按字符硬断(记 `hard_split`)。
- **缩字号**: `font*0.95^k` 逐级下降, 取「所有行不超宽且块高不超可用高」的最大字号,
  下限 `max(10, 0.6*font)`; 到下限仍超高时保留放得下的行并记 `clipped`, 绝不越出画面。
- **不重叠**: 矩形按边量化, 同一条字幕相邻行盒严格上下相接(共享边界, 面积交为 0),
  不同字幕之间保有正间隙, 因此任意两条激活字幕像素级不重叠(`overlap_px == 0`)。
- **等比**: 所有边距/间隙/行高都以 `font` 为单位; 当 `w:font` 与 `h:font` 同比缩放时,
  以字号为单位的布局逐项相同, 像素几何精确等差(2 倍分辨率 + 2 倍字号 = 2 倍矩形)。

## 输出

```json
{"frames":[{"f":0,"t":0.0,"active":["s0"],
            "rects":[{"text":"A","x":112.0,"y":209.6,"w":96.0,"h":20.8,"font":16.0,
                      "sid":"s0","line":0,"nlines":1}],
            "cover_px":1996.8,"occlusion_px":1996.8,"overlap_px":0.0,
            "degrade":[],"ncols":1,"dropped":[],"clipped":0}],
 "degrade":0,"overlap_px":0.0,"occlusion_px":0.0,
 "subs":[{"sid":"s0","t0":0.0,"t1":2.0,"text":"A"}],
 "stats":{"frames":100,"degrade_rects":0,"degrade_subs":[],"hard_split_subs":[],
          "dropped_subs":[],"clipped_lines":0,"max_columns_used":1,"overflow_frames":0,
          "cover_px":0.0,"cover_ratio":0.0,"overlap_px":0.0,"transitions":[...]}}
```

- `degrade`: 因超宽/超高而缩小字号的矩形计数(总量)。
- `occlusion_px` / `cover_px`: 该帧(全部帧累计)矩形面积和, 即遮挡面积。
- `overlap_px`: 矩形两两交叠面积累计, 设计上恒为 0。
- `stats.transitions`: 时间窗出现开/关变化的帧及具体条目, 用于逐帧核对边界。
- `--check`: 输出前跑独立校验(不同字幕不重叠、矩形不出画面、overlap_px 为 0), 失败即报错。

## 自测

`python3 selftest.py` 覆盖: 时间窗边界帧、重叠堆叠与像素不重叠、缩字号阶梯与硬断、
CJK 任意断行与多空格、输入顺序无关(12 次置乱逐字节相同)、3 字号 × 2 分辨率等比、
40 例随机模糊、CLI 端到端与输出确定性。
