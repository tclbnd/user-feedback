# 均衡器系数平滑与拉链噪声抑制

`python3 eq.py req.json output.json`

最小请求（与原始契约一致）：

```json
{"fs":48000,"blocks":64,"bs":64,"auto":[{"at":0.3,"biquad":{"g_db":12}}]}
```

输出：

```json
{"out":"out.wav",
 "coef_traj":[[b0,b1,b2,a1,a2], ...],        // 每个回调块一个点
 "coef_traj_bands":{"0":[[...], ...]},        // 每段每块
 "settle_ms":345.4,                           // 过渡时长
 "settle_time_ms":585.4,                      // 过渡完成绝对时刻
 "peak_db":-9.17, ...}
```

## 问题

原实现每块直接把整组系数换成目标值。换系数的那个采样点前后，滤波器的差分方程发生变化，
输出出现阶跃不连续 —— 拖动参数时听到的有节奏咔哒声，大增益频段的爆音即由此而来。

## 做法

1. **按采样级平滑**（`Band.advance`，每个采样点调用一次）
   - 平滑发生在**设计参数域**：增益 `g_db`、中心频率 `log(fc)`、`Q`。
     中心频率用 log 域插值，因此扫频在八度意义上是一条直线。
   - 每个采样点把参数朝目标推进一次，再由参数重新算出 5 个归一化系数
     `[b0,b1,b2,a1,a2]`。系数因此每个采样点只变化极小量，块边界不可能出现不连续。
   - 为什么不在系数域直接插值 `b0..a2`：当中心频率大幅移动时，两个稳定 biquad 之间的
     线性插值会得到**增益错误的中间滤波器**（200 Hz → 12 kHz 扫频实测偏差可达约 6 dB）。
     参数域插值的每一个中间状态都是有正确增益的合法 peaking 滤波器。
2. **两种插值形态**（`shape` / `interp`）
   - `exp`（默认）：一阶指数跟踪 `p += (target-p)·(1-e^{-1/τ})`，`τ` 默认 50 ms。
     因为每采样推进一次，轨迹只取决于采样率与 τ，与块大小、与扫频重定目标的频率都无关；
     目标是移动的（扫频）时，跟踪滞后恰为 τ。
   - `linear`：固定时长斜坡，`length` 默认 5τ，可用 `duration_ms` 指定。
   - 两种形态都会在剩余误差足够小时精确落到目标：指数形态按“相对起始距离的 1e-3”吸合
     （≈6.9τ，对应 `settle_ms`），因此过渡在有限时间结束、结束态与参考逐位一致。
3. **限幅与稳定域保护**
   - 每系数变化率限幅 `max_slew`（默认 5e-4，按系数幅值缩放，避免大系数时过渡被拉长到秒级）。
   - 目标参数清洗：增益夹到 ±240 dB，中心频率严格保持在 DC 与 Nyquist 之间（留 1e-9 相对保护带），
     Q 夹到 `[1e-3, 1e3]`；必要时把 `(a1,a2)` 投影回稳定三角。
   - **滤波器状态永不重置**：重定目标、块切换都只改系数，状态 (x[n-1],x[n-2],y[n-1],y[n-2])
     连续传递，因此不会注入冲击。
4. **多段同时变化**
   - 每段独立 `Band`，各自有系数、状态与自动化队列；输出为各段串级。
   - 各段在同一采样点检查并触发各自事件，同一采样点内互不影响。
5. **过渡中再次修改参数**
   - 重定目标时以**当前已平滑的参数值**为起点，所以轨迹仍然连续，并收敛到新目标。
   - 事件参数缺省时继承上一次目标（例如只写 `g_db` 就只改增益）。
6. **块大小无关**
   - 事件时刻、平滑计数器全部建立在**绝对采样网格**上，与宿主块大小无关。
   - 实测 4 种块大小（16/64/256/1024）渲染出的 int16 波形**逐位相同**；块大小只决定
     `coef_traj` 上报的粒度。
7. **扫频自动化**（`sweeps` / `sweep`）
   - `{from, to, from_s, to_s, scale:"log"}` 会展开成绝对时间网格上的事件序列。
   - 网格默认每 τ 一个点（可由 `steps` 指定）。
   - 一阶平滑跟随斜坡目标有 τ 的固有滞后，因此扫频默认带 `1.6τ` 的**超前补偿**
     （`lead_ms`，设 0 可关闭），把中段跟踪误差压到约 0.3 dB。

## 请求字段

| 字段 | 含义 |
| --- | --- |
| `fs` | 采样率，默认 48000 |
| `blocks`,`bs` | 渲染长度 = blocks×bs |
| `duration_s`/`duration` | 以秒指定长度（优先于 blocks×bs）；此时 `at` 仍按渲染比例解释 |
| `auto` / `automation` | 事件数组，见下表 |
| `bands` / `eq.bands` | 初始多段定义，每项 `{id?, biquad:{g_db,fc,q}}` |
| `shape` / `interp` | `exp`（默认）或 `linear` |
| `tau_ms` / `tau` | 指数时间常数，默认 50 ms |
| `max_slew` | 每采样每系数最大变化量，默认 5e-4；0 关闭 |
| `settle_eps` | 收敛容差，默认 1e-9 |
| `input:{tone_hz,amp}` | 测试信号，默认 440 Hz、幅度 8000 |

事件字段：`band`/`id`（默认 0）、`at`（占渲染比例；也可用 `at_s`/`at_ms`/`at_frac`/`at_sample`
指定绝对时间）、`g_db`、`fc`、`q`、`coef`（直接给 5 个归一化系数）、`shape`、`tau_ms`、
`duration_ms`、`settle_eps`、`max_slew`。

## 验收结果

见 `scratch/check.py`（开发用验证脚本）：

- 阶跃与扫频自动化对比逐采样参考：最大瞬时偏差 0.000 dB（≤0.5 dB），过渡后逐位一致；
- 爆音检测（对独立参数域参考的短窗残差）：≤ -68 dBFS（≤ -20 dBFS）；
- 4 种块大小：包络差 0.0（≤1e-4），int16 波形逐位相同；
- 过渡中重定目标：最终系数误差 0，收敛到新目标；
- 极限增益（±60 dB、单段 60 dB）与接近 Nyquist 的中心频率：所有中间系数均稳定。

原缺陷基线在同一条阶跃上二阶差分比修复后高 8.7 dB，即块边界的不连续。
