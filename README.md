# 保守实例遮挡裁剪

Python 3.9+，运行 `python3 cull.py demo.json output.json`。可选 `--no-cull` 使用全实例，`--workers N` 设置块查询并发度，`--reverse` 反转块遍历顺序用于确定性自检。scene 含 size=[宽,高]、near 和 frames。每帧给 occluders（rect 为屏幕整数半开矩形、z 为深度、opaque 为布尔）和 instances（id 唯一正整数、material 字符串、box=[x0,y0,z0,x1,y1,z1] 为相机空间包围体）。每一帧是独立几何位置，上一帧状态只可作为提示，不能替代当前遮挡证据。背景深度无限远。透明遮挡图元不写入遮挡深度。

## 绘制与保守裁剪规则

画面真值由 `cull.reference_render` 得出并保留其原始绘制规则（保留旧名 `render`）：像素中心为 x+.5,y+.5，半开矩形、严格深度测试，实例按 id 升序绘制。包围体分类与查询规则：

- **近面穿越**：`z0 < near <= z1` 时裁剪后的投影无界，直接保留；`z1 < near`（完全在近面后方）可无查询剔除。
- **部分屏外**：对四个 (x,z)/(y,z) 角点组合取投影极值，查询矩形按整像素向外取整（floor/ceil）并夹取到屏幕，只会减少裁剪；完全没有像素中心落在屏上的实例才剔除。
- **层级深度查询**：level 0 只由不透明遮挡物写入深度，向上做 2×2 **最大深度**归约。任何含未覆盖像素（深度无穷）的瓦片都保持无穷，因此部分覆盖的瓦片永远不能证明遮挡；深度相等按保留处理（严格 `<` 比较）。
- **透明遮挡资格**：`opaque=false` 的遮挡物不进深度金字塔，不能裁掉任何实例。
- 层级选择依据当前层级实际瓦片尺寸（尺寸非 2 的幂时同样安全夹取），查询覆盖包围体投影触及的全部瓦片，取其中最远深度与包围体最近深度 `max(near,z0)` 比较。

## 批次、回退与并行

- 保留实例先按 id 稳定排序，再按 material 字典序编组，批次内 ids 升序，同时保留材质名与实体标识。
- 上一帧结果以顺序无关的帧签名（遮挡物、实例、near、尺寸）作为可复用提示；签名不一致（运动后的常态）自动回退到完整重算，stats 中以 `fallback_recompute=true` 标记，签名一致时 `reused_previous=true` 且零查询。
- 实例按索引切成块，可由 `ThreadPoolExecutor` 跨工作线程处理；每个块写入独立槽位，合并严格按实例索引顺序。因此相同输入下，不同 worker 数、正/反遍历顺序甚至实例输入乱序，`kept`、`batches`、逐像素 `ids` 与 `hierarchy_queries` 完全相同。

每帧输出 kept（升序）、batches（按 material 排序，ids 升序）、ids（最终逐像素绘制 ID）、stats（含 hierarchy_queries、reused_previous、fallback_recompute、workers、blocks 与分类计数 reasons）。

## 验证

`python3 -m unittest test_cull -v` 共 13 个用例，以 `--no-cull` 完整渲染的逐像素实例 ID 作为独立参考：

1. 每组随机/序列场景都断言：凡在基线像素中出现的实例必在 kept 中（零误删），被裁实例在基线中无任何像素，且裁剪后的逐像素 ID 与基线完全相等；同时断言至少裁掉已知全遮挡对象。
2. 近面穿越、薄遮挡物、快速运动三组序列逐帧核对；薄边用例还对比朴素全局深度范围裁剪并证明其误删而本方案保留。
3. `large_occlusion.json` 为专设大面积遮挡样例（48 实例、中央遮挡墙），稳态裁掉 16/48 = 33.3%（≥25%），并在 1/4/8 worker、正/反遍历与输入乱序下断言批次成员与排序一致。
4. 另含透明遮挡不具资格、等深保留、完全屏外剔除、60 组随机场景模糊测试。
