# 各向异性高斯泼溅的排序混合与逐瓦片边界

`python3 splat.py input.json output.json`

input.json: `{"w":32,"h":32,"tile":8,"prims":[{"x":f,"y":f,"z":f,"sx":f,"sy":f,"sxy":f,"a":f,"rgb":[r,g,b]}...],"seed":1}`

模型约定：
- 2D 高斯核 G=exp(-0.5·dᵀΣ⁻¹d),覆盖半径按 3σ 分配到所有重叠瓦片
- 每瓦片按 z 键稳定排序后从前到后 alpha 混合:out=Σ a_i·G_i·T_i·rgb,T_i=Π(1-a_j·G_j)
- 跨瓦片边界不得截断高斯贡献；基元输入顺序变化不影响结果
- 深度等值基元次序稳定（见下）
- 输出 `{"pixels":[[r,g,b]*wh],"tile_counts":[[每瓦片基元数]],"pixel_counts":[逐像素贡献基元数],"digest":"sha1"}`

缺陷基线：画家算法不按深度 + 瓦片边界硬截断。

## 实现要点

**协方差投影与瓦片分配。** Σ=[[sx,sxy],[sxy,sy]] 求逆得核
`G(p)=exp(-0.5·dᵀΣ⁻¹d)`，覆盖半径 `3·sqrt(max(sx,sy))`。基元被分配到其 3σ 包围盒
**相交的每一个**瓦片，因此一个像素的贡献集合只由几何决定，与瓦片划分无关。

**不截断。** 每个瓦片只用来界定循环范围；写入像素的条件是「该像素在基元自己的
3σ 包围盒内」，而不是「该像素属于当前瓦片」。高斯在瓦片边界处从不被切断，接缝
两侧看到完全相同的基元集合。

**确定性排序。** 先把基元按**全序键** `(z, x, y, sx, sy, sxy, a, r, g, b)` 排序：
深度优先（从前往后），深度相等时按内容比较。既满足「深度等值基元次序稳定」，又
满足「输入顺序变化不影响合成」——两者只有在并列次序**不依赖输入顺序**时才能同时
成立。帧摘要对 w、h 与原始 IEEE-754 像素值取 sha1，因此重排输入或改变瓦片尺寸后
摘要逐位一致。

## 验收测试

```
python3 tests/selftest.py       # 精度 / 接缝 / 重排与瓦片尺寸不变性 / 逐瓦片与逐像素计数
python3 tests/test_mutations.py # 变异测试：证明上面这套检查确实能抓到缺陷
```

`tests/selftest.py` 覆盖：
- **精度**：与「无瓦片、逐像素解析积分」参考比较，ROI 相对误差 ≤ 1%。
- **接缝**：跨瓦片边界两侧的亮度差，与同一场景在「只有一整块瓦片」下的渲染逐位
  相同（扰动 = 0）；在低梯度场景上另加 ≤ 0.004 的绝对跳变判据。
- **不变性**：3 次随机重排 + 12 种瓦片尺寸（含非整除尺寸），摘要与像素逐位一致。
- **计数**：`tile_counts` 与独立重建的「瓦片×基元」重叠集合完全一致；
  `pixel_counts` 与解析支撑集一致。

`tests/test_mutations.py` 注入四个缺陷（输入序画家算法、瓦片边界截断、仅按深度
排序导致并列不稳、两个基线缺陷合并），并断言测试确实失败。
